# 🎮 XOMQA — квиз-крестики-нолики

Онлайн-игра для стримов и дружеских дуэлей: классические крестики-нолики скрестили с викториной. Чтобы поставить свою фигуру на поле — отвечай на вопрос правильно. Дуэль чисел, очереди зрителей к стримеру и режим «соперник найдётся сам» — всё в одном файле.

**Играть:** https://tihomirsvetozarov0-debug.github.io/xomqa/

## 🕹 Режимы игры

- **Создать / присоединиться по коду** — классическая онлайн-дуэль: создатель получает код комнаты, друг вводит его и подключается.
- **🎬 Ведущий — лобби очереди** — стример открывает лобби, зрители записываются в очередь, стример принимает любого и играет с ним.
- **🙋 Зритель — записаться к стримеру** — вход в очередь по своему Twitch-нику.
- **🎲 Игра между участниками** — поиск соперника без стримера: каждый вводит ник, система сводит пару.

## 🧩 Уровни сложности

| Уровень | Поле | Линия | Попытки | Бомбы |
|---|---|---|---|---|
| Лёгкий | 3×3 | 3 | 3 | нет |
| Средний | 4×4 | 4 | 4 | нет |
| Высокий | 5×5 | 4 | 5 | нет |
| Всезнайка | 6×6 | 4 | 6 ❤ | 4 бомбы |
| Вундеркинг | 7×7 | 6 | 3 ❤ | 6 бомб |

На «Всезнайке» и «Вундеркинге» на поле спрятаны бомбы: наступил — взрыв и поражение. Каждый ход становится лотереей 💣

## ⚔️ Дуэль чисел

Перед игрой каждый называет число от 1 до 50 — оно влияет на расклад дуэли. Побеждает серия и тактика, а не только знания.

## 🚀 Как запустить локально

1. Склонируйте репозиторий или скачайте `index.html`.
2. Откройте файл в браузере — это весь запуск, сборка не нужна.
3. Для мультиплеера игра использует Firebase (авторизация и синхронизация комнат настраиваются в консоли Firebase).

## 🛠 Технологии

- Чистый HTML/CSS/JS — один файл, без сборщиков и фреймворков.
- Firebase: анонимная авторизация и Realtime-синхронизация комнат.
- Хостинг: GitHub Pages.
